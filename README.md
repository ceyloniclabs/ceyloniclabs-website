# 🦁 Ceylonic Labs — Official Corporate Website

> **"Innovating Heritage Through Technology"**  
> Official corporate Single Page Application (SPA) for Ceylonic Labs — an agile software venture studio & engineering product lab founded in Sri Lanka.

---

## ⚡ Tech Stack & Architecture

- **Core**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS v4 + Obsidian Glassmorphism Design Tokens
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans, Outfit, JetBrains Mono
- **Deployment**: GitHub Pages (Custom domain: `ceyloniclabs.com`) via GitHub Actions CI/CD

---

## 🚀 Key Features

1. **Single Page Application (SPA) with Smooth Scroll**:
   - Header navigation links automatically scroll down smoothly to respective sections (`Products`, `Services`, `Milestones`, `About`, `Pricing`, `Contact`).
   - Dynamic active section indicator synchronized with window scroll position.

2. **Accurate Company Knowledge & Brand Guidelines**:
   - High-contrast **Obsidian Noir** (`#05070C`), **Electric Cyan** (`#00E5FF`), and **Ocean Cobalt** (`#1C64F2`) palette.
   - Vector-crisp official **Ceylonic Tech Lion** (*තාක්ෂණික සිංහ සංකේතය*) brand marks.

3. **Flagship SaaS Showcases**:
   - **TCMS (Tuition Class Management System)**: Sub-second QR gate attendance, automated tuition fee ledger, 4-tier RBAC, student smart ID cards, and parent SMS alerts.
   - **SurfDesk (Surfboard Rental & Retail POS)**: Mobile cloud check-in, paperless digital waivers with touch e-signatures, before-and-after photo damage matrix, overtime grace periods, and barcode retail POS.

4. **Custom Engineering & Agile Milestones (Model B)**:
   - Structured 4-stage sprint delivery (30%-40% Kickoff, 30% Core MVP, 20%-30% Feature complete & UAT, 10% Handover & 30-Day Warranty).

5. **The 3-Founder Story**:
   - Founded by 3 software engineer friends operating a 100% remote-first lab in Sri Lanka.
   - Frontline empathy: Tested for real-world chaotic conditions (crowded tuition gates, beach counters with wet hands).

6. **Dynamic Auto-Incrementing Copyright Year**:
   - The footer dynamically renders `{new Date().getFullYear()}`, automatically updating without manual code edits.

## 🛠️ Development & Build Scripts

```bash
# Install dependencies
npm install

# Start local development server (runs on http://localhost:5173/)
npm run dev

# Compile TypeScript and build production bundle into ./dist
npm run build

# Preview production build locally
npm run preview
```
